Nirun Platform: How a Report Is Built
Build data points → AI pre-fill → Assign owners → Fill in → Review data → Write sections → Owners confirm → Translate → Design → Final check

Build the data point list. Start from last year's report structure and past reports. AI suggests new data points to match IFRS, GRI and TCFD, and CSSM approves each one. Each data point is a number or a text answer, with guidance on what to fill in and which standard it answers.

AI pre-fills. AI fills in data points from past reports and CSSM news, shows the source of each answer, and marks anything out of date.

Assign owners. CSSM gives each data point to an owner with a due date. Each owner gets a link to only their own list.

Fill in data points. Owners check the pre-filled answers, enter numbers with a source file, and write short text answers. The platform sends reminders. When the owner presses Submit, the status turns from red to orange and CSSM gets an email.

Review data. CSSM either returns the data with comments or accepts and locks it. The platform flags any number that doesn't match across the report. To change locked data, the owner asks CSSM first. Every change is recorded.

Write sections. CSSM clicks Generate, and AI writes each section from the accepted data in the style of past reports. CSSM edits the text, and AI suggests better wording and checks spelling and missing parts. AI never changes a number. A wrong number is fixed in its data point and updates everywhere.
Owners confirm. Owners read the finished section about their area, then confirm it or leave comments for CSSM to fix.

Translate. AI translates Thai to English using Thaioil's approved word list. A reviewer checks both languages side by side. CSSM then freezes the content.

Design. AI lays out the report in Thaioil's past report design and turns tables into charts. On a canvas, users click any part and type what to change, or edit it by hand. Prompts can change the look but not the words or numbers. The report exports as PDF, PPTX, images, or editable files for an agency.

Final check. The platform compares every page with the frozen content, so no word or number is changed or cut. Owners check their pages, and the report is ready.
